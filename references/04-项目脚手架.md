# 04 项目脚手架

按本规则生成插件工程，占位符 `{{xxx}}` 替换为实际值。

## csproj 模板（骨架）

```xml
<Project Sdk="Microsoft.NET.Sdk">

  <PropertyGroup>
    <TargetFramework>{{TargetFramework}}</TargetFramework> <!-- 由版本解析确定，如 net9.0 -->
    <RootNamespace>$(MSBuildProjectName)</RootNamespace>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
    <GenerateAssemblyInfo>false</GenerateAssemblyInfo>
    <AssemblyName>{{插件名}}</AssemblyName>
  </PropertyGroup>

  <ItemGroup>
    <PackageReference Include="TShock" Version="{{TShockVersion}}" />
  </ItemGroup>

</Project>
```

要点：
- `TargetFramework`：Phase 1 解析出的 TFM（如 `net9.0`）
- `TShock` 包版本 = 目标 TShock 版本
- 无对应 NuGet 包（门禁例外场景）→ 改为 `<Reference Include="TShockAPI"><HintPath>{{本地TShockAPI.dll路径}}</HintPath></Reference>`

## 项目结构

```
{{插件名}}/
├── {{插件名}}.csproj
├── {{插件名}}.sln
├── Plugin.cs               # 主类：插件信息/路径/事件注册释放/配置重载
├── Commands.cs             # 聊天命令注册与处理（无命令可省略）
├── Configuration.cs        # 配置文件类
├── CacheData.cs            # 缓存/数据文件类（高频数据，可省略）
├── Utils.cs                # 工具方法（消息格式化等，按需）
├── Core/                   # 业务逻辑纯类（可单测，不碰运行时静态状态）
│   └── {{业务类}}.cs
├── README.md               # 使用说明（命令表/权限表/配置说明）
└── tests/                  # xunit 测试项目（有可测逻辑时）
    └── {{插件名}}.Tests.csproj
```

## 解决方案与命令

- `dotnet new sln -n {{插件名}}` + `dotnet sln add`
- 构建：`dotnet build -c Release`
- 测试：`dotnet test`

## 命名规范

| 项 | 规则 | 示例 |
|---|---|---|
| 插件名/程序集 | 英文 PascalCase | `ItemPool` |
| 命名空间 | 与插件名一致 | `namespace ItemPool;` |
| 类名 | 职责命名 | `Commands`、`Configuration` |
| 方法 | 动词开头 | `LoadConfig`、`GetData` |
| 中文配置项 | JSON 属性用中文可读名 | `[JsonProperty("插件开关")]` |

## 占位符清单

| 占位符 | 来源 |
|---|---|
| `{{TargetFramework}}` | Phase 1 版本解析（如 net9.0） |
| `{{TShockVersion}}` | Phase 1 版本解析（如 6.1.0） |
| `{{插件名}}` | Phase 0 需求采集 |
| `{{作者}}` / `{{版本}}` / `{{描述}}` | Phase 0 需求采集 |
